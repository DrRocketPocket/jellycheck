Features

  • Watched Avatars: Shows who watched each title directly on media posters.
  • Storage Bar: Live storage bar at the top of the start page for all users.
  • Ultra.cc / Seedbox Quota: Queries Sonarr/Radarr API for exact slot storage limits.

Auto-Delete & Storage Settings

Configure Sonarr/Radarr credentials, auto-cleanup of watched media, and start page storage display.

⚠️ Heads up: Auto-delete removes files from disk when all users have watched them. Items with favourites are never deleted, and nothing is blacklisted.
📺 TV Shows
Enable Auto-Delete for Shows Master toggle. When off, no shows are ever auto-deleted.
Grace Period (days) Days to wait after all users finish a show before deleting it. New episodes reset the clock automatically.
🎬 Movies
Enable Auto-Delete for Movies Master toggle for movies. Off by default.
Grace Period (days) Days to wait after all users watch a movie before deleting it.
🛡️ Protection
Skip Favourited Items If any user has clicked favourite on a show or movie, never delete it regardless of watched status.
🟢 Sonarr (Series & Storage)
Sonarr URL e.g. http://localhost:8989 or https://user.ultracc.com/sonarr
Sonarr API Key Found in Sonarr → Settings → General → Security
🟡 Radarr (Movies & Storage)
Radarr URL e.g. http://localhost:7878 or https://user.ultracc.com/radarr
Radarr API Key Found in Radarr → Settings → General → Security
🔵 Overseerr / Jellyseerr
Overseerr URL e.g. http://localhost:5055 or http://overseerr:5055
Overseerr API Key Found in Overseerr → Settings → General
📊 Start Page Storage Bar
Show Storage Bar on Start Page Displays a progress bar at the top of the Jellyfin start page for all users showing remaining disk space.
Storage Plan Size (GB) Your slot or server plan limit in GB (e.g. 6000 for a 6 TB plan). When set, this takes priority so remaining space is estimated as: Plan Size − Library Media − Outside Usage. Leave empty to disable.
Media in Jellyfin library: Calculating...
Current Free Storage on Slot (GB) Type what storage is left right now from your seedbox or provider panel (e.g. 56 GB). Jellycheck calculates the outside library usage for you automatically. As your Jellyfin library grows with new content in the future, the remaining space adjusts itself automatically.
Used Outside Library (GB) Space taken by files Jellyfin cannot see: seeding torrents, active downloads, app data. Auto-calculated when you enter remaining space above, or enter it manually.

Notify Before Deletion Log a prominent warning N days before a title gets deleted.
Notify N Days Before How many days before deletion to fire the notification.
